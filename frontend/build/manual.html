⚙️ Entegrasyon Kurulumları ve API Anahtarları

CorteQS Intelligence Engine, kurumsal verilerinizi toplamak için çeşitli harici servislerle entegre çalışır. Bu bölümde her bir entegrasyon için gerekli API anahtarları, ne işe yaradıkları ve nasıl alınacakları detaylı olarak açıklanmaktadır.

🔐 Güvenlik Notu Tüm API anahtarları sunucu tarafında güvenli bir şekilde saklanır ve asla istemci tarafına gönderilmez. Anahtarlarınızı kimseyle paylaşmayın.

💬 Slack Entegrasyonu

Ne İşe Yarar?

Slack entegrasyonu, workspace'inizdeki iletişim verilerini CorteQS'e aktarır:

  • Kullanıcılar: Tüm workspace üyeleri "Person" düğümü olarak kaydedilir
  • Kanallar: Public ve private kanallar "Topic" düğümü olarak eklenir
  • Mesajlar: Kanal mesajları "Document" düğümü olarak indekslenir
  • İlişkiler: Kim hangi kanalda yazdı, kim kime cevap verdi gibi bağlantılar kurulur

Neden Gerekli?

Kurumsal iletişiminizi aranabilir ve analiz edilebilir hale getirir. AI Asistan'a "Geçen hafta marketing kanalında ne konuşuldu?" gibi sorular sorabilirsiniz.

Gerekli Credential

Değişken Format Açıklama
SLACK_BOT_TOKEN xoxb-... veya xoxe-... Slack Bot User OAuth Token

Nasıl Alınır?

Slack API Sayfasına Gidin

https://api.slack.com/apps adresine gidin.

Yeni App Oluşturun

"Create New App" → "From scratch" seçin. App adı ve workspace belirleyin.

OAuth & Permissions Ayarlayın

Sol menüden "OAuth & Permissions" seçin. "Bot Token Scopes" altına şu izinleri ekleyin:

  • channels:history - Kanal mesajlarını okuma
  • channels:read - Kanal listesini görme
  • users:read - Kullanıcı bilgilerini okuma
  • users:read.email - Email adreslerini okuma
  • files:read - Paylaşılan dosyaları okuma

Workspace'e Yükleyin

"Install to Workspace" butonuna tıklayın ve izinleri onaylayın.

Token'ı Kopyalayın

"Bot User OAuth Token" değerini kopyalayın. xoxb- ile başlar.

⚠️ Kanal Erişimi Bot'un mesajları okuyabilmesi için ilgili kanallara eklenmesi gerekir. Public kanallar için bot'u kanala davet edin: /invite @botadı

🐙 GitHub Entegrasyonu

Ne İşe Yarar?

GitHub entegrasyonu, kod tabanınız ve proje yönetimi verilerinizi CorteQS'e aktarır:

  • Repository'ler: Tüm repo'larınız "Project" düğümü olarak kaydedilir
  • Issue'lar: Açık/kapalı issue'lar "Document" düğümü olarak eklenir
  • Pull Request'ler: PR'lar "Document" düğümü olarak indekslenir
  • Contributor'lar: Katkıda bulunanlar "Person" düğümü olarak eklenir
  • Commit'ler: Commit mesajları ve geçmişi analiz edilir

Neden Gerekli?

Kod tabanınızı ve proje geçmişinizi aranabilir hale getirir. "Bu özellik hangi PR ile eklendi?", "Kim bu modülde en çok çalıştı?" gibi sorulara cevap bulabilirsiniz.

Gerekli Credential

Değişken Format Açıklama
GITHUB_TOKEN ghp_... veya github_pat_... Personal Access Token

Nasıl Alınır?

GitHub Settings'e Gidin

https://github.com/settings/tokens adresine gidin.

Yeni Token Oluşturun

"Generate new token" → "Fine-grained tokens (Beta)" seçin.

Token Ayarlarını Yapın

  • Token name: "CorteQS Integration"
  • Expiration: 90 gün veya daha uzun
  • Repository access: "All repositories" veya spesifik repo'lar

İzinleri Seçin

"Repository permissions" altında:

  • Contents: Read - Dosya içeriklerini okuma
  • Issues: Read - Issue'ları okuma
  • Pull requests: Read - PR'ları okuma
  • Metadata: Read - Repo bilgilerini okuma

Token'ı Oluşturun ve Kopyalayın

"Generate token" tıklayın. Token sadece bir kez gösterilir, hemen kopyalayın!

💡 İpucu Fine-grained token'lar daha güvenlidir çünkü sadece belirli repo'lara ve izinlere erişim verirsiniz.

📁 Google Drive Entegrasyonu

Ne İşe Yarar?

Google Drive entegrasyonu, bulut depolamanızdaki dokümanları CorteQS'e aktarır:

Neden Gerekli?

Kurumsal dokümanlarınızı merkezi olarak aranabilir hale getirir. "Marketing planı nerede?", "2024 bütçe tablosu kim tarafından hazırlandı?" gibi sorulara cevap bulabilirsiniz.

Gerekli Credential

Değişken Format Açıklama
GOOGLE_SERVICE_ACCOUNT_JSON JSON dosyası Service Account credentials

Nasıl Alınır?

Google Cloud Console'a Gidin

https://console.cloud.google.com adresine gidin.

Paylaşım Adımları:

🕸️ Neo4j Aura (Graf Veritabanı)

Ne İşe Yarar?

Neo4j, CorteQS'in "beyni"dir - tüm bilgi grafiğini saklar ve yönetir:

  • Düğümler (Nodes): Kişiler, projeler, dokümanlar, konular
  • İlişkiler (Edges): Kim kime bağlı, ne neyle ilişkili
  • Graf Sorguları: "A kişisi hangi projelerde çalıştı?" gibi karmaşık sorgular
  • Graf Algoritmaları: PageRank, Community Detection, Shortest Path

Neden Gerekli?

İlişkisel veritabanları (MySQL, PostgreSQL) ilişkileri verimli sorgulayamaz. Neo4j, "3 adım uzaklıktaki tüm bağlantıları bul" gibi sorguları milisaniyede çözer.

Gerekli Credentials

Değişken Format Açıklama
NEO4J_URI neo4j+s://xxxxx.databases.neo4j.io Bağlantı adresi
NEO4J_USER neo4j Kullanıcı adı (genellikle "neo4j")
NEO4J_PASSWORD Rastgele string Veritabanı şifresi

Nasıl Alınır?

Neo4j Aura'ya Gidin

https://neo4j.com/cloud/aura/ adresine gidin.

Ücretsiz Hesap Oluşturun

"Start Free" ile kayıt olun. Free tier aylık 200k node destekler.

Yeni Database Oluşturun

"Create Database" → Database adı girin (örn: "corteqs") → Region seçin → "Create"

Credentials'ı Kaydedin

Database oluşturulduktan sonra şifre sadece bir kez gösterilir!

  • Connection URI
  • Username (neo4j)
  • Password

Hemen not edin veya ".env credentials" dosyasını indirin.

⚠️ Şifre Uyarısı Neo4j Aura şifreyi sadece database oluşturulduğunda gösterir. Kaybederseniz şifreyi sıfırlamanız gerekir.

🔍 Elasticsearch Cloud (Arama Motoru)

Ne İşe Yarar?

Elasticsearch, CorteQS'in "arama motoru"dur - tüm içeriklerde hızlı arama sağlar:

  • Full-Text Search: Tüm doküman içeriklerinde arama
  • Fuzzy Matching: Yazım hatalarına toleranslı arama ("proje" yerine "porje" yazsan da bulur)
  • Autocomplete: Yazarken öneri gösterimi
  • Highlighting: Bulunan kelimeleri vurgulama
  • Aggregations: İstatistik ve gruplama

Neden Gerekli?

Neo4j yapısal sorgular için mükemmeldir ama metin araması için değil. Elasticsearch, milyonlarca doküman içinde milisaniyede arama yapabilir.

Gerekli Credentials

Değişken Format Açıklama
ELASTICSEARCH_CLOUD_ID deployment:base64string Cloud deployment kimliği
ELASTICSEARCH_API_KEY Base64 encoded string API erişim anahtarı

Nasıl Alınır?

Elastic Cloud'a Gidin

https://cloud.elastic.co adresine gidin.

Ücretsiz Trial Başlatın

14 günlük ücretsiz deneme ile başlayın. Kredi kartı gerekmez.

Deployment Oluşturun

"Create deployment" → Deployment adı girin → Region seçin → "Create deployment"

Cloud ID'yi Alın

Deployment oluştuktan sonra "Manage" → Overview sayfasında "Cloud ID" görünür.

API Key Oluşturun

"Security" → "API Keys" → "Create API Key"

  • Name girin (örn: "corteqs-access")
  • "Create API Key" tıklayın
  • Encoded değerini kopyalayın (Base64 formatında)
💡 İpucu Elastic Cloud 14 gün sonra ücretli olur. Alternatif olarak self-hosted Elasticsearch da kullanılabilir, ancak yönetimi daha zordur.

❓ Sıkça Sorulan Sorular

Verilerim güvende mi?

Evet. Tüm veriler şifreli bağlantılar üzerinden iletilir ve güvenli cloud altyapılarında saklanır. Google OAuth kullanıldığı için şifreniz bizimle paylaşılmaz.

Hangi dosya türleri destekleniyor?

Google Docs, Sheets, Slides tam içerik çıkarımı destekler. PDF, DOCX, TXT dosyaları yüklenebilir ve AI ile analiz edilebilir.

Ne kadar veri saklayabilirim?

Pratik bir sınır yoktur. Neo4j ve Elasticsearch cloud altyapıları ölçeklenebilir şekilde çalışır.

AI yanıtları doğru mu?

AI, sadece bilgi tabanınızdaki verilere dayanarak cevap verir. Ne kadar çok kaliteli veri eklerseniz, cevaplar o kadar doğru ve kapsamlı olur.

Slack mesajlarım neden görünmüyor?

Slack bot'unuzun ilgili kanallara erişim izni olmalıdır. Bot'u kanallara ekleyin veya public channel erişimi verin.

Google Drive dosyalarım neden görünmüyor?

Dosyalarınızı service account email'i ile paylaşmanız gerekir. Paylaştıktan sonra "Sync" butonuna basın.

Destek nasıl alabilirim?

AI Asistan'a sorularınızı sorabilir veya teknik destek için support@corteqs.net adresine yazabilirsiniz.
